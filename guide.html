Let's make this page yours

This is your personal profile website, built with the same HTML, CSS and JavaScript you've been learning all term. This guide walks through customizing it, adding your own projects, and publishing it live on GitHub Pages.

1. Find your files

Your project is split into three files. Each one has a different job.

FileWhat it's for
index.html The content of your page — your name, bio, projects, and links.
style.css Colours, fonts, spacing, and animations — how everything looks and moves.
script.js The interactive bits — dark mode, the mobile menu, and the name animation.

2. Replace the placeholder content

Everything here is placeholder content for a made-up student. Open index.html and work through this list — your progress is saved automatically, even if you close this page.

3. Link your real GitHub projects

Each project card needs two links — swap both into your own repo.

<a href="https://github.com/yourusername/your-repo-name">View code</a>
<a href="https://yourusername.github.io/your-repo-name">Live demo</a>

Only have one or two finished projects? Delete the extra <article class="project-card"> block instead of leaving a fake one in place.

4. Animate your name

Your name on the hero is split into individual letters in script.js, which lets style.css animate each one separately with @keyframes. Three styles are built in — try them below, then open index.html and add the matching class to the <h1 class="hero-name"> element.

Try Me

<h1 class="hero-name name-wave">Your Name</h1>

5. Try changing the theme colours

Open style.css and find the :root section near the top. These are CSS variables — change a value once and it updates everywhere it's used.

--accent-coral
--accent-sunshine
--accent-sky

6. Put it on GitHub

  1. Create a new repository on GitHub. Name it yourusername.github.io to publish it at the root of your GitHub Pages site.
  2. Add index.html, style.css, script.js and this guide.html to the repository.
  3. Commit and push, just like you've done with your other projects.
  4. In the repository's Settings → Pages, set the source to your main branch.
  5. Wait a minute, then visit the URL GitHub gives you — your profile is live.

Open your browser's DevTools console on the live page — there's a small message waiting for you there.
